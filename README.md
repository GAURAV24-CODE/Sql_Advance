🌟 About the Repository
SQL Advanced --- Interview Mastery is a practical PostgreSQL-based
learning repository designed to build SQL skills from fundamentals to
advanced interview-level problem solving.

The repository follows a progressive approach:

Learn → Practice → Solve Problems → Build Analytical Thinking →
Prepare for Interviews

Instead of learning SQL only through syntax, this repository focuses on
understanding how SQL works, how queries execute, how to analyze data,
and how to solve business-style problems.

🎯 Main Goals
🧩 Build strong SQL fundamentals

🔎 Master filtering, sorting, aggregation, and conditional logic

🔗 Understand and apply different types of JOINs

🧠 Solve subquery and EXISTS problems

📊 Analyze data using window functions

🧹 Perform SQL-based data cleaning

⚡ Understand SQL performance and optimization

🏗️ Learn database design concepts

💼 Prepare for Data Analyst / Data Scientist interviews

🧪 Practice SQL with realistic datasets and interview questions

🧩 Query Execution Flow
A core concept throughout this repository is understanding the logical
order in which SQL processes a query.

FROM
  ↓
JOIN
  ↓
WHERE
  ↓
GROUP BY
  ↓
HAVING
  ↓
SELECT
  ↓
DISTINCT
  ↓
ORDER BY
  ↓
LIMIT
Example
SELECT
    department,
    COUNT(*) AS employee_count,
    AVG(salary) AS avg_salary
FROM employees
WHERE salary > 30000
GROUP BY department
HAVING COUNT(*) >= 3
ORDER BY avg_salary DESC
LIMIT 5;
Understanding this flow makes complex SQL much easier to reason about.
