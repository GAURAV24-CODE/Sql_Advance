# 📌 Day 5 Overview

Day 5 focuses on learning how to **group records and perform analysis on each group** using SQL.

The module builds on the aggregation functions learned in Day 4 and introduces `GROUP BY` and `HAVING`, which are essential for data analysis and SQL interviews.

The module is organized around:

- 📊 `GROUP BY`
- 🔢 Multiple-Column `GROUP BY`
- 🔎 `HAVING`
- ⚖️ `WHERE` vs `HAVING`
- 🔀 `GROUP BY` with `CASE`
- 🧪 Hands-on practice
- 💼 Interview questions
- 📋 Quick revision with a cheatsheet

### 🎯 Main Goal

Learn how to **group data, calculate aggregate results for each group, and filter groups based on aggregate conditions**.
