# 📌 Day 11 Overview

Day 11 focuses on learning how to **organize, simplify, and execute complex SQL queries using Common Table Expressions (CTEs)** in PostgreSQL.

The module builds on the SQL concepts learned during previous days and introduces CTE techniques used in real-world data analysis, reporting, and SQL interviews.

The module is organized around:

* 🔹 Basic CTE
* 🔗 Multiple CTEs
* 🤝 CTE with `JOIN`
* 📊 CTE with Aggregation
* 🔄 Recursive CTE
* ⚖️ CTE vs Subquery
* 🧪 Hands-on SQL practice
* 📋 Quick revision with a cheatsheet
* 💼 Interview preparation

### 🎯 Main Goal

Learn how to **write structured, readable, and efficient SQL queries using CTEs** and apply them to practical data analysis problems.
