# 📌 Day 3 Overview

Day 3 focuses on learning how to **control the order and number of records returned by a SQL query** and how to create conditional results using `CASE WHEN`.

The module builds on the filtering concepts learned in Day 2 and introduces sorting, result limitation, and conditional logic.

The module is organized around:

- ↕️ `ORDER BY`
- ⬆️ `ASC` and `DESC`
- 🔢 Multiple-Column Sorting
- 🔽 `LIMIT` with `ORDER BY`
- 🔀 `CASE WHEN`
- 🧠 Conditional Logic
- 🧪 Hands-on practice
- 💼 Interview questions
- 📋 Quick revision with a cheatsheet

### 🎯 Main Goal

Learn how to **sort query results, retrieve the required number of records, and create conditional outputs using SQL logic**.
