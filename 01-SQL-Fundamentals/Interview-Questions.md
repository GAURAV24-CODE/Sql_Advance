==================================================
          SQL INTERVIEW QUESTIONS — DAY 1
==================================================

1. What is SQL?
SQL is used to store, retrieve, manipulate, and manage data in databases.

2. What is SELECT?
SELECT is used to retrieve data from a database table.

3. What is FROM?
FROM specifies the table from which data should be retrieved.

4. What does SELECT * mean?
It returns all columns from the specified table.

5. What is DISTINCT?
DISTINCT removes duplicate values from the query result.

6. What is an alias?
An alias is a temporary name given to a column or table.

7. What is AS used for?
AS is used to assign an alias to a column or table.

8. Can we perform calculations in SELECT?
Yes. We can perform arithmetic calculations such as +, -, *, and /.

9. What is LIMIT?
LIMIT restricts the maximum number of rows returned by a query.

10. What is NULL?
NULL represents a missing, unknown, or unavailable value.

11. How do you check for NULL?
Use IS NULL.

12. How do you check for NOT NULL?
Use IS NOT NULL.

13. Can we use = NULL?
No. Use IS NULL instead of = NULL.

14. Does SELECT modify data?
No. SELECT only retrieves data; it does not modify the table.

15. What does semicolon (;) mean?
It marks the end of an SQL statement.

16. What is a calculated column?
A column created using an expression or calculation in the SELECT statement.

17. What is a table alias?
A temporary short name assigned to a table, commonly used to make queries shorter.

18. Does an alias change the actual column name?
No. An alias only changes the name displayed in the query result.

==================================================
