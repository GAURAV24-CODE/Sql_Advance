# 📌 Day 2 Overview

Day 2 focuses on learning how to **filter specific rows from a table** using SQL conditions.

The module builds on the SELECT and FROM concepts learned in Day 1 and introduces the `WHERE` clause and different filtering techniques.

The module is organized around:

- 🔎 `WHERE`
- ⚖️ Comparison Operators
- 🔗 `AND`, `OR`, `NOT`
- 📋 `IN`, `NOT IN`
- 🔢 `BETWEEN`
- 🔤 `LIKE`, `ILIKE`
- ❓ NULL Filtering
- 🧪 Hands-on practice
- 💼 Interview questions
- 📋 Quick revision with a cheatsheet

### 🎯 Main Goal

Learn how to retrieve **only the rows that satisfy specific conditions**.
