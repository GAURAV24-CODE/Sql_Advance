19. DAY 8 FINAL REVISION
==================================================

UNION
→ Combine unique rows

UNION ALL
→ Combine every row

INTERSECT
→ Find common rows

EXCEPT
→ Find differences

WHERE
→ Filter each SELECT

JOIN
→ Combine related tables before set operation

ORDER BY
→ Sort final result

LIMIT
→ Restrict final result

5-second interview rule:

UNION      = Unique
UNION ALL  = All
INTERSECT  = Common
EXCEPT     = Difference
